六種稀有度

白、藍、黃、紫是隨機產生的裝備；橘（傳奇）與紅（神話）是固定設計，只有數值在小範圍內浮動。主倍率乘在劍、斧、弓的基礎傷害、法杖的法術強度，或防具的基礎防禦；戒指與護身符沒有基礎攻防，主倍率改為放大所有詞綴。

掉落機率

每次掉落先決定「掉什麼」（裝備、藥水、金幣或什麼都沒有），掉到裝備時再依下表擲稀有度。神話要物品等級 10（第 10 層）以上才會出現，否則降為傳奇。

「每次擲骰掉裝備」＝裝備在該張表的比重；精英怪是在原本的掉落之外再擲一次精英表。橘、紅的欄位是「掉到裝備時」的稀有度比例。

上表是第 1～4 層的基本比例。越深的樓層會再放大黃以上的權重（白、藍不變；商人賭博不套用），倍率依序是黃 / 紫 / 橘 / 紅：5～14 層 ×1.2 / 1.4 / 1.4 / 1.5、15～19 層 ×1.4 / 1.8 / 1.8 / 2、20～24 層 ×1.5 / 3.6 / 3.6 / 4、25 層起 ×1.6 / 4.4 / 4.4 / 5.2。第 25 層起每件裝備是紫 / 橘 / 紅的機率：一般怪物約 2.5% / 0.31% / 0.05%、精英 10.1% / 1.7% / 0.30%、魔王 28.5% / 5.9% / 1.4%、寶箱 5.7% / 0.94% / 0.13%。

物品等級與詞綴階級

物品等級＝掉落的樓層。物品等級決定兩件事：能掉哪些基底，以及詞綴的數值階級。

詞綴階級物品等級（樓層）固定值詞綴百分比詞綴加成類詞綴
  • 詞綴數值 = 基本範圍 ×（1 + 成長 ×（階級 − 1））× 稀有度倍率。同一件裝備所有詞綴共用一個稀有度倍率。
  • 成長：固定值（傷害、防禦、生命等）每階 +50%；百分比（攻速、暴擊、抗性等）每階 +15%；加成類（近戰 / 遠程 / 法術傷害、附加元素傷害）每階 +25%。
  • 基底：只掉等級需求 ≤ 物品等級、且不低於物品等級 − 15 的基底；每個部位至少保留最高的一種。深層不會再掉最初級的短劍。
  • 傳奇 / 神話：基底固定取該種類目前能用的最高階；固定屬性同樣隨詞綴階級成長（預設每階 +15%），特殊效果的數值不變。
items.ts · 8 階

裝備基底

武器與防具分 8 階，每階數值約 ×1.4～1.5。武器的數字是基礎傷害，防具是基礎防禦。主倍率乘在劍、斧、弓的基礎傷害、法杖的法術強度、防具的防禦。武器種類另有內建加成，不隨階級變動；可用的技能類別由武器決定（v0.4.0 武器允許矩陣）：劍斧＝近戰＋魔法＋戰術、弓＝遠程＋魔法＋戰術、法杖＝魔法＋戰術。武器基礎加成 V1.0（設計者 2026-11-21）：劍 近戰 +9%；斧 近戰 +7%、暴擊 +2%；弓 遠程 +7%、暴擊 +1%；法杖 法術 +6%，依技能類型生效。劍斧弓原本的法術 −20% 已拿掉，但沒有法術強度，要靠「武器灌注」取得；灌注只繼承法術強度，不繼承法杖的法術 +6%。

affixes.ts

詞綴

一般詞綴出現在白～黃（紫、橘、紅也有固定數量的一般詞綴）；強屬性只出現在紫以上。數值為稀有度倍率 100% 時的範圍；紫會再 ×1.2～1.5。

吸血 / 吸魔硬上限：技能「血之汲取 / 魔力汲取」1～5 級為 +0.1%～0.5%；其他每一個來源（詞綴、傳奇 / 神話屬性、條件效果、回復造成傷害的一部分）最高 +0.3%，超過時一律以 0.3% 計算（舊存檔也一樣）；例外是「暴擊時回復傷害的一部分」最高 +0.5%，鼓勵提升暴擊率。近戰技能的吸血效果 ×1.3、多個來源可以累加。要往上調必須先討論。

傳奇與神話

橘讓某一招變得好用：主倍率＋3 條固定屬性＋1 條強屬性＋1 條傳奇效果。紅改變整個 Build 或 Combo：主倍率＋4 條固定屬性＋3 條神話效果。戒指與護身符沒有主倍率，改為多一行屬性。每種裝備有橘 12 件、紅 6 件；一部分橘色取材自地牢裡的怪物，新的紅色對應每 5 層的魔王（造型與效果都參考魔王），從該魔王的樓層起才會掉落。盾牌只能搭配劍或斧，效果多半在「格擋」時發動。屬性數值為第 1～7 層（T1）的範圍。

熔核：鑲嵌與融合

把用不到的裝備（2～4 件，飾品以外）在商人那裡熔成「熔核」，再鑲進自己裝備的孔：武器熔成攻核（銳、重、穿、靈），防具與盾牌熔成護核（壁、疾、掌、冠）。融合的核種、核階、核色由規則決定（按下融合前就看得到），數值、副屬性與印記由骰子決定。同一顆熔核鑲在不同部位效果不同。

    融合試算

    放 2～4 件裝備（飾品以外：武器 → 攻核、防具與盾牌 → 護核；四件同一類 = 純核，屬性多一條）與 0～2 件飾品，用遊戲的融合判定算出按下融合前就確定的部分：核種、核階、核色、元素、條數、印記機率，以及鑲在各部位的主屬性範圍與費用。數值以紫裝為準；鑲在白 / 藍 / 黃 / 橘裝上再乘 ×0.5 / 0.6 / 0.75 / 1.25。

    賣價、拆解、飛昇、光芒

    賣價與買價

    金幣尺度（設計者 2026-11-21）：買賣價、藥水、賭博、重鑄、飛昇、鑿孔、融合、洗點的金幣全部是原本的 2 倍，精華與碎片不變；路上撿到的金幣同時變多（掉落表的金幣每深一層 +35%，結晶獸 600～3,000），正常進度到第 20 層累積撿到約 7.5 萬（原本 1.9 萬）。舊存檔的金幣讀檔時 ×2，購買力不變。賭博一次 = 60 + 20 × 樓層。

    飛昇（商人，把基底換成下一階）

    v0.5.0 起金幣與精華是原本的 2 倍（鑲好熔核的裝備是長期投資；飛昇後孔與熔核保留）；2026-11-21 金幣再 ×2（金幣尺度，精華不變）。精華：武器用武器精華，其他部位用防具精華。第 5 階起另需飛昇碎片（第 5 階 1 片、第 8 階 4 片）；魔王有 60% 機率掉 1～2 片。戒指與護身符不能飛昇。

    一鍵賣出、一鍵拆解與洗點

    商人可以一鍵賣出背包裡的白色、白＋藍、白＋藍＋黃裝備；同一排下面的「一鍵拆解」把同樣範圍的裝備直接拆成精華（每件照「拆解得到的精華」擲數量；穿在身上的、熔核、藥水與倉庫不動）。鑲著熔核的裝備兩個按鈕都不會動，整件留在背包：熔核要不要取下、拆解由玩家自己決定。洗點（重置技能點 / 屬性點）在技能頁與角色頁：金幣 = 係數 × 等級^1.5（技能 60、屬性 40），Lv30 約 9,900 / 6,600 金幣。

    地牢遺物：12 件執念物＋8 件無主遺物

    打怪時撿到的特別物品，不能裝備、不能鑲嵌、不能加工，也賣不掉。共 20 件：12 件執念物是 12 個盜墓者各自真正想要的東西，交給他會發生只屬於他的事件；8 件無主遺物沒有人要，純收集，每件都是以前死在井裡的人留下的故事。和《井誌》的「遺物」（地上翻開、記進井誌的舊紙）是兩種東西。

    怎麼拿到

    • 20 件都靠打怪掉落，只在各自的樓層區間：一般怪 0.1%、精英 0.5%、魔王 2%（初版）。
    • 每層約 170 隻（清 85%），區間 6～9 層約 1,000～1,500 隻，一件的累積取得機率約 63%～78%：一般玩家大約拿得到三分之二，不保證全拿。
    • 全遊戲只有一件：在身上或已經交出去就不會再掉；丟在地上又離開那一層，那件就消失，之後有機會再掉。
    • 撿到就自動放進背包的地牢遺物區（20 格，不佔一般背包）；商人那裡一律賣不掉，一鍵賣出、一鍵拆解也碰不到。

    要回哪一層找誰

    • 撿到執念物時跳出提示：「好像有個盜墓者在找它。」
    • 物品說明與圖鑑寫想要它的人和他現在在哪一層：見過他寫名字，沒見過寫「某個盜墓者」；他已經不要了、或永久離開了也會寫出來。
    • 盜墓者會自己往下走：同一個人同時只在一個地方；辦完事、你離開那一層，他就走到下一個預定的樓層；你先到了他下一個預定的樓層，他也會跟上來（接了沒交的任務照樣能交）。不用回頭找人。
    • 任務本自動多一筆「誰在找這個？」；交了就打叉。
    • 帶著他的執念物走進他會出現的那一層，他的位置一開始就標在小地圖上。
    • 盜墓者本人要自己在那一層找；他站在離怪物遠的地方，附近的怪清完才能說話。

    交給他

    • 只有執念物能交，任何時候都能交：不用先接任務、不用先完成他的正式任務。
    • 點他開交付格子，手動從地牢遺物區拿出那一件放進去：確定就被他拿走，取消就回到遺物區；放錯的放不進去。
    • 交的時間會改變結果：例如醉鬼的釣魚竿，5、13 層交他會回家；18、24 層他已經不記得釣魚是什麼，不收。
    • 會永久離開的人，如果負責解鎖隱藏魔王，告別時會順便說出秘密並解鎖（目前只有烏鴉：頭冠＝奪界雙手）。

    收藏與圖鑑

    • 地牢遺物區兼收藏：在身上正常顯示；交出去的變暗，懸停只寫「交給了某某」，點了沒作用；弄丟的變暗、寫「弄丟了」。
    • 圖鑑多一個「遺物」分頁。每件的頁面：左上角小圖，圖的右邊是名稱、種類、說明與掉落樓層；下面是交給了誰、在第幾層、他收到時說的整段話；無主遺物則記下每個盜墓者看到它時說的話。
    • 對話聽過一次就永久存在圖鑑（存進存檔）。還沒拿到過的是剪影與「？？？」。
    • 20 件全部拿到過（交出去的也算）有一次收集獎勵（待定）。
